# Upstream sync

> **Intended use:** if this app was scaffolded from a template (copied, not forked), there's no shared git history to cherry-pick across. Track **generic** improvements made here — anything that would help _any_ app built on the template, not tied to this app's domain — so they can be contributed back by hand. Delete this file if the app was forked with shared history (use `git` directly instead).

## How to use (agents + humans)

- Made a change that's **generic**? Add a row to **Candidates**.
- **Exclude app-specific things**: domain schema, branding/theme values, feature code, anything only this app needs. Those stay here.
- Status flow: `candidate` → `upstreamed` (pushed to the template) → or `n/a`.
- Optional: add an `Upstream: <note>` trailer to the commit so candidates are greppable later.
