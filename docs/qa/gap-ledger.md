# Gap ledger

Seeded 2026-10-20 from the specs below. One row per checkable claim. A later `/loop` works the TODO rows one at a time following [gap-loop.md](gap-loop.md); it sets a row to RED (gap confirmed) or GREEN (behaviour correct, test kept) and writes its finding under [Findings](#findings). Ids are stable; append new rows at the end of an area with the next free id. Synthetic values only; nothing here comes from `data/raw`.

## Legend

Status: `TODO` not yet checked · `COVERED` an existing assertion checks the claim · `QUESTION` the sources contradict each other or leave the expected value open · `RED` gap confirmed by the loop · `GREEN` behaviour confirmed by the loop.

Layer: `engine` (Kotlin test under `engine/`) · `frontend` (Vitest under `frontend/src`) · `browser` (the running app, proven by the browser-validator agent, no test file).

Sources: `A` docs/rules/A-profile-discrepancy.md · `B` docs/rules/B-high-risk-pep.md · `C` docs/rules/C-flow-through.md · `ESC` docs/rules/escalation.md · `PRI` docs/rules/priority.md (paper scorecard, superseded by ADR-0033) · `DESIGN` docs/engine/rules-engine-design.md · `APP` docs/challenge/app-rules.md · `S` docs/challenge/company-specific-rules.md · `MQ` docs/challenge/mentor-questions.md (§ names the question; only filled **Answer:** lines are cited) · `README` docs/challenge/README.md · `BRIEF` docs/challenge/finreg-challenge.md · `CFG` engine/src/main/resources/triage/triage-config-v1.json (the versioned triage data of ADR-0033) · `ADR-nnnn` docs/DECISIONS.md.

Paths: `E/` = `engine/src/test/kotlin/cz/morosystems/aml/engine/` · `F/` = `frontend/src/`. For a COVERED row the path names the test class or file and the test method. For a TODO row it names the file the loop should write to (create it when missing). For a browser row it is the scenario the browser-validator runs.

Thresholds come from DESIGN §Seed rules (A1 `projected_pct` 25, A2 `avg_multiple` 3, A3 `max_multiple` 2, B1 `country_min` 10 000 CZK, B2 `pep_min` 100 000 CZK, C1 `min_inflow` 100 000 CZK and `forward_pct` 80). The `DETECTION` constants in APP are stale and are not used here.
